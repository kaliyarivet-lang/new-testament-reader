Import a UTF-8 JSON file with verse pairs. The reader will keep the imported text in this browser's local storage, without uploading it anywhere. JSON format:

{"Matthew":{"1":[{"v":1,"gr":"Greek text","en":"English text"}]}}

Book names must match the book selector. You may import licensed NA28 and NRSVue material that you are authorized to use. The offline sample is Textus Receptus Greek and Challoner Douay–Rheims English. Other chapters load the original 1582 Douay–Rheims English online when available (not the Challoner revision); import Greek and Challoner verse pairs for full offline parallel reading, not NA28 or NRSVue.
